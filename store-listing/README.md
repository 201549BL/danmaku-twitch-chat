# Chrome Web Store relaunch package

This directory contains the production assets and copy for the Danmaku for Twitch store relaunch.

## Upload order

1. Upload the release package whose version matches `manifest.json`.
2. Set the title to `Danmaku for Twitch — Chat Overlay`.
3. Paste the summary and detailed description from `listing-copy.md`.
4. Upload screenshots from `screenshots/` in numeric order.
5. Upload the small and marquee promo images from `promo/`.
6. Upload `video/danmaku-for-twitch-promo.mp4` to YouTube and add its URL as the localized promo video.
7. Add the GitHub repository as the website/support destination and keep the existing privacy-policy URL.
8. In the locale selector, add Japanese, Simplified Chinese, and Traditional Chinese copy from `locales/`. Upload matching localized screenshots when they are available.

## Before the next listing refresh

Replace the current synthetic stream screenshots with creator-approved Twitch footage that shows the real extension UI. Keep the filenames and order, but use these messages:

1. `Twitch chat, directly on the video.`
2. `Customize it without leaving the stream.`
3. `Readable even when chat explodes.`
4. `Never miss friends, mods, or mentions.`
5. `Move and resize it anywhere.`

The opening seconds of the promo video should show the before/after result immediately. Aim for a 15–20 second cut, then show customization and busy-chat handling.

All store screenshots are 1280×800. Promo assets use the Chrome Web Store's required 440×280 and 1400×560 sizes.
